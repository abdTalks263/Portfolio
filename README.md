# M. Abdullah Latif - Portfolio Website

A modern, responsive portfolio website showcasing my projects, skills, experience, and professional journey as a Full Stack Developer.

## What is This Portfolio?

This portfolio website serves as a comprehensive digital representation of my professional identity and work. It provides visitors with:

- **About Me**: An introduction to who I am, my background, and my passion for software development
- **Skills & Expertise**: A detailed overview of my technical skills across frontend, backend, mobile development, and other technologies
- **Portfolio**: A showcase of my projects including web applications, mobile apps, and full-stack solutions with live demos and GitHub links
- **Experience**: My professional work history and contributions at various companies
- **Contact**: A way for potential employers, clients, or collaborators to reach out

The portfolio is designed with modern UI/UX principles, featuring smooth animations, glass morphism effects, gradient designs, and a fully responsive layout that works seamlessly across all devices.

## Technologies Used

- **React.js**: Frontend framework for building the user interface
- **TypeScript**: For type-safe code
- **Tailwind CSS**: For modern, responsive styling
- **EmailJS**: For contact form functionality
- **React Hooks**: For state management and side effects
- **Intersection Observer API**: For scroll-triggered animations

## Features

- ✨ Modern, animated UI with glass morphism effects
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🎨 Gradient text and background effects
- ⚡ Smooth scroll animations
- 📧 Contact form with EmailJS integration
- 🔗 Direct links to GitHub repositories and live demos
- 📄 Resume download functionality
- 🌙 Dark theme optimized design

## Installation

1. Clone the repository
```bash
git clone [repository-url]
cd portfolio-tailwind
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```
